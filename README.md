# ElecMoinsChere — site web

Site statique : questionnaire qui génère le prompt Claude (`index.html`) et tableau des prix relevés (`prix.html`).

- Les prix sont lus en direct dans la base [elec-moins-chere-prix](https://github.com/NicolasPopy/elec-moins-chere-prix) (mise à jour chaque jour). `data/offres.json` est une copie de secours si la base est inaccessible.
- Hébergement : GitHub Pages (Settings → Pages → branche `main`, dossier racine), avec le nom de domaine personnalisé dans le même écran.
